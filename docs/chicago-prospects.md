# Palate — Chicago Prospect List

Chicago is an ideal first market for Palate. The city has a dense, sophisticated wine culture spanning independent wine bars, Michelin-starred restaurants with serious wine programs, an active corporate event scene, and large-format venue spaces. Palate's three core modes — Booth, Wine Crawl, and Festival — map directly onto how Chicago hosts already run tastings. This list covers businesses most likely to see immediate value.

## Outreach Priority

**Start here (highest fit + easiest entry):**
1. The Sommelier Company — high volume, professional operator, natural partner
2. Chicago Winery / City Winery — already built for wine events, infrastructure in place
3. Brix Catering & Events — turnkey partnership, they bring the events
4. Volo, Rootstock, Pompette — independent wine bars, owner-operated, faster decisions

**Second wave (fine dining, hotels, and focused wine bars):**
- Acanto, Spiaggia, Oriole — premium reference clients, slower sales cycle
- The Gwen, Lacuna Events — venue scale justifies Annual License or Enterprise conversation
- Pops for Champagne — strong fit for champagne-focused tasting events; confirm they run structured tastings (vs. casual open-floor service) before pitching
